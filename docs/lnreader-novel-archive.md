# Using Novel Archive with LNReader

This guide shows how to add the Novel Archive plugin repository to LNReader and install the Novel Archive source.

## 1. Install LNReader

Install LNReader for Android from the official LNReader release page:

https://github.com/lnreader/lnreader/releases

LNReader supports Android 7.0 and newer.

## 2. Add the Novel Archive plugin repository

LNReader 2.x uses plugin repositories. Open the plugin/repository management screen in LNReader and add this repository manifest:

```text
https://raw.githubusercontent.com/5ghzx/novelarchive-lnreader/plugins/master/.dist/plugins.min.json
```

If your LNReader build asks for a repository URL, use the URL above.

## 3. Install Novel Archive

After adding the repository, refresh the repository list. Find **Novel Archive** and install it.

The repository is maintained at:

https://github.com/5ghzx/novelarchive-lnreader

## 4. Search and read

Open LNReader's source/search interface, select **Novel Archive**, and search for a novel. Open a result to view its available chapters and start reading.

## 5. Updating

When the repository publishes a newer plugin build, refresh the plugin repository in LNReader and update the Novel Archive plugin if an update is offered.
